Installatie (GitHub Pages)

  1. Maak een GitHub repo (bv. planten-databank).
  2. Kopieer alle bestanden uit deze map naar je repo.
  3. Enable GitHub Pages: Settings → Pages → “Deploy from branch” → main → root.

BOBO (2-level selectie)

De BOBO-keuzes komen uit data/layers/bobo_bodemcodes_volledige_lijst.xlsx (sheet alle_codes met kolommen groep en code).

Voor de echte BOBO “paint” upload je per lettergroep een bestand zoals:

  • data/layers/BOBO_A.xlsx
  • data/layers/BOBO_E.xlsx …

De app matcht op Latijnse naam en (optioneel) leest ze een codekolom (bv. code of bodemcode) om te filteren op de gekozen bodemcode.

Regionale soortenlijst

De district-dropdown komt uit data/layers/List_options_regionale_soortenlijst.xlsx (kolom Districten).

Per district verwacht de app een Excel-bestand in data/layers/ met de naam:

<Districtnaam met spaties → underscores>.xlsx

Voorbeeld: Oost-Kempisch puinwaaierdistrict → Oost-Kempisch_puinwaaierdistrict.xlsx.

Hoe werkt de mapping?

De app probeert eerst data/layers/backbone_lists.xlsx te laden (jouw backbone). Als dat niet lukt, gebruikt ze data/config.json.

Kolommen (minimaal)

  • Latijnse naam (key)
  • Nederlandse naam
  • Optioneel filters: kenmerk_bodemtype, kenmerk_bodemvochtigheid, kenmerk_zuurtegraad

Tip voor latere uitbreiding

Je kan extra filters toevoegen door extra kolommen te lezen (bv. licht, hoogte, wind, luchtverontreiniging, voedselrijkdom). Het patroon blijft hetzelfde.
